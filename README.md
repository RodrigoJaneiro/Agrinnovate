# AgrInnovate

## 🌱 Sobre o Projeto
A **AgrInnovate** é uma solução inovadora para a modernização da agricultura, baseada em sensores avançados que monitorizam variáveis ambientais em tempo real. O nosso objetivo é proporcionar aos agricultores informações precisas sobre as condições das suas plantações, permitindo tomadas de decisão mais eficientes e sustentáveis.

## 🚀 Objetivos
- Fortalecer o setor agrícola através da tecnologia.
- Reduzir desperdícios e otimizar o uso de recursos naturais.
- Democratizar o acesso à agricultura inteligente para pequenos e médios produtores.
- Proporcionar uma ferramenta intuitiva e acessível sem necessidade de conhecimento técnico avançado.

## 🏆 Benefícios do AgrInnovate
✅ **Monitorização em tempo real**: Dados instantâneos sobre temperatura, humidade do solo e do ar, intensidade de luz, velocidade e direção do vento, e precisão da chuva.
✅ **Eficiência e sustentabilidade**: Uso racional da água e energia, otimizando a produção agrícola.
✅ **Fácil instalação e utilização**: O kit acompanha um manual digital para orientação do utilizador.
✅ **Notificações e alertas**: Avisos sempre que os dados saírem dos parâmetros ideais.
✅ **Aplicação intuitiva**: Acesso via smartphone para visualização dos dados e histórico das medições.

## 📦 O Que Inclui o Kit AgrInnovate?
O sistema é composto por:
- **Sensores** de temperatura, luminosidade, humidade do solo e do ar.
- **Estação meteorológica** para medir velocidade do vento, direção e precisão da chuva.
- **Módulo ESP32** para transmissão de dados via Wi-Fi/Bluetooth.
- **Aplicação móvel** para acompanhamento remoto dos dados recolhidos.
- **Painel solar e bateria** para autonomia e sustentabilidade energética.

## 📊 Funcionalidades da Aplicação
🔹 **Monitorização dos sensores** com atualização em tempo real.
🔹 **Alertas automáticos** para condições adversas.
🔹 **Gráficos interativos** para análise de tendências.
🔹 **Integração com API meteorológica** para previsão climática.
🔹 **Configuração personalizada** de limites ideais.
